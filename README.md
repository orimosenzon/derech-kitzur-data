# דרך קיצור, מסד הנתונים

השבילים וקיצורי הדרך של פרדס חנה-כרכור. **זהו מקור האמת של היוזמה**, ולא עותק.

האפליקציה קוראת מכאן ישירות, ועורכים כותבים לכאן מתוכה. הקוד עצמו יושב במקום אחר:
[orimosenzon/fun/vibe_coding/dereh_kitzur](https://github.com/orimosenzon/fun/tree/master/vibe_coding/dereh_kitzur).

האפליקציה: https://orimosenzon.github.io/fun/vibe_coding/dereh_kitzur/

## מה יש כאן

```
data/trails.json   השבילים ונקודות הציון. הקובץ היחיד שקובע.
data/layers.json   שכבות תוכנית רשת הרכיבה של המושבה
img/               תמונות, שם הקובץ הוא hash של התוכן
```

## למה ריפו נפרד

הנתונים היו עד 22/8/2026 בתוך שכבת Google My Maps של היוזמה. גוגל לא מאפשרת לכתוב
אליה מקוד בשום דרך, ולכן כל שביל חדש חייב לעבור ייבוא ידני. הפיכת הכיוון פותרת את זה:
נכתב לכאן, ומכאן מייצרים למפה עותק לצפייה.

הריפו נפרד מריפו הקוד בכוונה. מפתח הכתיבה שעורך מחזיק בטלפון מוגבל לריפו הזה בלבד,
כך שגם אם ידלוף הוא לא נוגע בשום דבר אחר.

## מבנה של שביל

```json
{
  "id": "p52",
  "name": "דרך קיר הרעש",
  "note": "",
  "photos": [{"thumb": "img/d1ef..._t.webp", "full": "img/d1ef....webp"}],
  "path": [[32.478208, 34.953383], [32.474441, 34.950904]],
  "length": 479,
  "color": "#097138",
  "entries": [{"lat": .., "lng": .., "view": [.., ..], "heading": 286, "likely": true}],
  "origin": "mymaps",
  "added": "2026-08-22T05:46:00+00:00"
}
```

הנתיבים ב-`photos` יחסיים לשורש הריפו. `origin` הוא `mymaps` למה שיובא מהמפה המקורית
ו-`app` למה שנוסף מהאפליקציה. `entries` הן שתי הכניסות לשביל, עם מיקום מצלמה וזווית
לסטריט ויו.
